# 🎛️ 亲密调音台｜五轴强度控制

> **即点即玩：** [打开在线《亲密调音台》](https://vitasid57.github.io/bluntcore-intimacy-lab/microtoys/intimacy-mixer/) · [对应理论原文](<./理论原文/intensity-dials.md>) · [搭配《关系机关局》](https://vitasid57.github.io/bluntcore-intimacy-lab/microtoys/mechanism-play/)

## 这是什么

把互动的「词汇、心理、控制、节奏、感官」拆为五条**彼此独立**的轴，每轴 0–3 四档。它不是将所有体验归结为一个强度总分，而是生成**当前回合**的表达配置。

## 怎么玩

1. 选「慢热贴近」「脑内拆解」「权限游戏」「高压沉浸」「直白温柔」等预设。
2. 拖动五条滑杆，自行微调；不想被改变的轴可锁定。
3. 查看五轴雷达图；需要一点偶然性就点「随机微调未锁定轴」。
4. 复制 Prompt 或 JSON，交给自己的 AI。网页可将档位保存到本地浏览器。

## 隐私与限制

不要求账号、不将资料上传服务器。自定义档位保存在当前浏览器的 localStorage 中；本轮情境不写入长期记忆。任何档位都不能覆盖实时意愿、人格、身份或当前边界。MCP 代码见仓库 `tools/bluntcore-mcp/`（若已安装）。

## 理论与制作

原样附上 DUDU-X 历史分支的《五轴强度旋钮》作为理论核对稿，网页为独立重新实现的交互工具；特定用户的专属设定不随网页公开。
