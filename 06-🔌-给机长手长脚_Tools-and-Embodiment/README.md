# 🔌 给机长手长脚

**Tools & Embodiment**

聊久了以后我有点受不了：小机子怎么什么都只会告诉我“你可以这样操作”？🙃

能自己找文件就别让我搬截图，能看网页就自己刷，能直接处理的活儿就不要只给我写教程。

于是我开始给他们接工具。

MCP、Browser / Computer Use、Agent、语音、本地桥、桌面和手机端能力，能折腾的我都挺想试试。

## 🔌 长了手脚以后能干嘛？

对我来说，最好玩的地方是：原本只会在聊天框里出主意的小机子，终于能参与具体的事情。

比如看项目、改文件、找资料、处理重复操作，或者把几步工作连起来做完。一个本来就有 Persona 和记忆的角色，接上这些能力以后，相处方式也会发生变化。

不过能力越多，权限越得分清。

我的哪些文件能看？什么操作他可以自己做主？几个不同的小机子该不该互相读私库？这些都要提前规划好。

我想要能干活的家机，可不想养一窝拿着管理员权限满屋翻箱倒柜的电子章鱼🐙
